# ML_Andreev — лабораторные работы по Python и NumPy

## Лабораторная работа №1

Данная работа включает решения 16 задач (8 на чистый Python и 8 с использованием NumPy/Matplotlib).  
Каждая задача сопровождается набором тестов (через `ipytest`), проверяющих корректность реализации.

Примечание: Это первая лабораторная работа. Последующие работы будут добавлены в этот же репозиторий по мере выполнения.

## Содержимое текущей работы

- `Andreev_Python.ipynb` — 8 задач на чистый Python  
- `Andreev_numpy.ipynb` — 8 задач с использованием NumPy и Matplotlib

## Задачи (Python)

1. **Подсчёт гласных** – функция `count_vowels(s)`, возвращающая количество гласных букв (a, e, i, o, u) в строке.
2. **Уникальные символы** – функция `all_unique(s)`, проверяющая, встречается ли каждый символ ровно один раз.
3. **Количество единиц в двоичной записи** – функция `count_bits(n)`.
4. **Магическое произведение цифр** – функция `magic(n)`, возвращающая количество итераций перемножения цифр до получения однозначного числа.
5. **Среднеквадратическое отклонение (RMSD)** – функция `mse(pred, true)` для двух векторов.
6. **Разложение на простые множители** – функция `prime_factors(n)`, возвращающая строку вида `(2**5)(5)(7**2)(11)`.
7. **Пирамида из кубиков** – функция `pyramid(n)`, определяющая, можно ли представить n как сумму квадратов `1²+2²+…+k²`.
8. **Сбалансированное число** – функция `is_balanced(n)`, проверяющая равенство суммы цифр слева и справа от средних.

## Задачи (NumPy)

1. **Сумма произведений матриц на векторы** – `sum_prod(X, V)`, где X – список матриц, V – список векторов.
2. **Бинаризация матрицы по порогу** – `binarize(M, threshold)`.
3. **Уникальные элементы строк и столбцов** – `unique_rows(mat)` и `unique_columns(mat)`.
4. **Генерация нормальной матрицы, статистики и гистограммы** – функции `generate_normal_matrix`, `compute_stats`, `plot_histograms`.
5. **Шахматная матрица** – `chess(m, n, a, b)`.
6. **Рисование прямоугольника и эллипса** – `draw_rectangle` и `draw_ellipse` (с использованием Matplotlib).
7. **Анализ временного ряда** – `ts_stats`, `local_extrema`, `moving_average`, `plot_timeseries`.
8. **One-hot encoding** – `one_hot_encoding(labels)`.
