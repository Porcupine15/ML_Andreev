# ML_Andreev — лабораторные работы по Pandas и корреляционному анализу

## Лабораторная работа №2 (Pandas + Корреляционный анализ)

Данная работа состоит из двух частей:

1. **Основы Pandas** – обработка датасета `titanic.csv`: загрузка, очистка, фильтрация, сортировка, группировка.
2. **Корреляционный анализ** – исследование взаимосвязей в датасете `brainsize.txt`: диаграммы рассеяния, расчёт коэффициента Пирсона, визуализация через тепловые карты (Seaborn).

Все задания выполнены в формате Jupyter Notebook.

---

## Содержимое работы

- `Andreev_Pandas.ipynb` (или `pandas_lab.ipynb`) – задания по обработке данных Titanic.
- `Andreev_Correlation.ipynb` (или `correlation_lab.ipynb`) – корреляционный анализ набора `brainsize.txt`.
- `titanic.csv` – исходные данные о пассажирах «Титаника».
- `brainsize.txt` – данные о 40 студентах (размер мозга, IQ, вес, рост, пол).

---

## Задания (Pandas – Titanic)

1. **Загрузка и предпросмотр** – чтение CSV, вывод первых 10 строк.
2. **Проверка на пропуски** – использование `isna()` и заполнение нулями (`fillna(0)`).
3. **Фильтрация** – выбор строк с `Age > 30`.
4. **Сортировка** – упорядочивание по `Fare` по убыванию.
5. **Группировка** – средний возраст по классам (`Pclass`).

---

## Задания (Корреляционный анализ – brainsize)

### Часть 1. Подготовка данных
- Загрузка `brainsize.txt` (разделитель – табуляция).
- Просмотр первых/последних записей (`head(10)`, `tail(8)`).
- Статистический обзор (`describe()`).

### Часть 2. Диаграммы рассеяния
- Разделение выборки по полу (`menDf`, `womenDf`).
- Построение scatter‑plot зависимости «средний IQ» → `MRI_Count`.

### Часть 3. Расчёт корреляции
- Матрица корреляции Пирсона для всего набора, для мужчин и женщин.
- Анализ полученных коэффициентов (почему диагональ равна 1, почему матрица симметрична, интерпретация значений, близких к нулю).

### Часть 4. Визуализация
- Построение тепловых карт (heatmap) с помощью `seaborn`.
- Сравнение корреляционных структур для мужчин и женщин.

**Вопросы, на которые даны ответы в ноутбуке:**
- Почему на главной диагонали матрицы корреляции стоят единицы?
- Почему значения под диагональю зеркально повторяют значения над диагональю?
- Что означает коэффициент корреляции, близкий к нулю?
- Зачем было выполнено разделение по полу?
- Какие переменные сильнее всего коррелируют с размером мозга (`MRI_Count`)? Ожидаемо ли это?
