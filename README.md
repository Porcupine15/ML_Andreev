# ML_Andreev — классические алгоритмы и линейные модели

## Лабораторная работа №3

Данная работа состоит из двух частей:

1. **Классические алгоритмы без ансамблирования** – сравнение логистической регрессии, дерева решений и метода k-ближайших соседей на датасете `german.csv` (бинарная классификация кредитоспособности). Выполнен подбор гиперпараметров через `GridSearchCV`, визуализация ROC-кривых и анализ важности признаков.

2. **Реализация линейных моделей с нуля** – самостоятельное программирование линейной регрессии (MSE, градиентный спуск) и логистической классификации (сигмоида, кросс-энтропия). Модели обучены на датасетах `Student_Performance.csv` (регрессия, предсказание индекса успеваемости) и `german.csv` (классификация).

## Часть 1. Классические алгоритмы (german.csv)

**Цель:** предсказать `Creditability` (1 – кредитоспособен, 0 – нет).

### Предобработка
- Удалён признак `Foreign_Worker`.
- Масштабирование признаков `StandardScaler` (важно для LogReg и KNN).
- Выборка: 80% – обучающая, 20% – тестовая.

### Подбор гиперпараметров (GridSearchCV, 5‑fold CV)

| Модель               | Лучшие параметры                                                                 |
|----------------------|----------------------------------------------------------------------------------|
| Logistic Regression  | `C=0.001`, `solver='liblinear'`, `class_weight=None`                            |
| Decision Tree        | `max_depth=6`, `min_samples_split=20`, `class_weight='balanced'`                |
| KNN                  | `n_neighbors=31`, `weights='distance'`, `metric='manhattan'`                    |

### Результаты на тестовой выборке

| Модель               | Accuracy | ROC‑AUC | Precision | Recall |
|----------------------|----------|---------|-----------|--------|
| **Logistic Regression** | 0.775    | **0.7861**  | 0.8163    | 0.8696 |
| Decision Tree        | 0.685    | 0.6979  | 0.8261    | 0.6884 |
| KNN                  | 0.765    | 0.7750  | 0.7571    | 0.9710 |

**Оценка по ROC‑AUC:** Logistic Regression – **8 баллов**.

### Анализ важности признаков (Decision Tree)
Наибольший вклад: `Account_Balance`, `Payment_Status_of_Previous_Credit`, `Duration_of_Credit_monthly`.

### Эксперименты с гиперпараметрами
- **LogReg:** оптимальное `C=0.01` (сильная регуляризация, без переобучения).
- **KNN:** лучший `k=31`, метрика `manhattan`.
- **Decision Tree:** глубина `>6` ведёт к переобучению.

ROC-кривые и графики влияния гиперпараметров приведены в ноутбуке.

## Часть 2. Линейные модели с нуля

### 2.1 Линейная регрессия (Student Performance)
- **Цель:** предсказать `Performance Index` (10–100 баллов) по 5 признакам.
- **Модель:** собственный класс `LinearRegressor` (MSE, градиентный спуск).
- **Результаты:**  
  - MSE = 4.15, RMSE = 2.04, MAE = 1.62, **R² = 0.9888**.
  - Наиболее важный признак – `Previous Scores` (вес +0.919).
- **График обучения:** `learning_rate=0.1` даёт быструю сходимость.

### 2.2 Логистическая классификация (German Credit)
- **Цель:** предсказать `Creditability`.
- **Модель:** `LinearClassifier` (сигмоида, BCE, градиентный спуск).
- **Результаты:**  
  - Accuracy = 0.767, **ROC‑AUC = 0.8009**, Precision = 0.8005, Recall = 0.8886, F1 = 0.8422.
- **Важность признаков:** сильный положительный вклад – `Account_Balance`, `Value_Savings_Stocks`.
- **Обучение:** лучшие параметры – `lr=0.01`, `epochs=2000`.

Все метрики и графики (кривая обучения, ROC-кривая, веса признаков) доступны в ноутбуке.
